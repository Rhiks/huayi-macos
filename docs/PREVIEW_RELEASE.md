## Huayi Preview

这是 Huayi 的通用预编译预览版，包含 Intel（x86_64）与 Apple Silicon（arm64）架构。下载 DMG 后，把 Huayi 拖入 Applications 即可。

> [!IMPORTANT]
> 当前包使用 ad-hoc 本地签名，尚未经过 Apple Developer ID 签名与公证。macOS 可能阻止首次直接打开；请在 Finder 中右键 Huayi，选择“打开”，并确认只从本仓库的 Release 页面下载。

首次运行后，还需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 Huayi。

`SHA256SUMS.txt` 可用于核对下载文件完整性。当前版本不包含自动更新；升级时请重新下载新版，或使用源码安装流程。
